How Home Studio works

  1. Open a project and start a new design. Everything for the post sits in one panel: template, size, colours, copy and images.
  2. Add other sizes from the same design; the copy stays in sync while each size keeps its own image crops.
  3. Review, then download a PNG or JPG at full size.

Designs are saved in this browser only. Need a new template or layout? Ask Potting Shed.
